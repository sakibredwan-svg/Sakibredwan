# MD. Sakib Redwan — Light Minimal Portfolio

A clean, modern, light portfolio website for MD. Sakib Redwan.

## Included
- `index.html` — portfolio structure
- `style.css` — responsive light/minimal design
- `script.js` — mobile navigation, scroll progress and reveal animations
- `assets/sakib.jpg` — supplied portrait
- `assets/MD-Sakib-Redwan-CV.pdf` — supplied CV

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload all files and the `assets` folder to the root of your GitHub Pages repository. Keep `index.html` at the repository root.
